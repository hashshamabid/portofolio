# House Price Prediction

## Project Overview
This project predicts house prices using machine learning techniques and feature engineering.

## Dataset
The dataset contains information about residential properties including:
- Bedrooms
- Bathrooms
- Living area
- Lot size
- House age
- Renovation status
- Location features

## Feature Engineering
Created additional features:
- House Age
- Renovation Indicator
- Bathroom-to-Bedroom Ratio
- Living Area per Bedroom

## Models Tested
- Linear Regression
- Ridge Regression
- Decision Tree
- KNN Regressor
- Random Forest
- Gradient Boosting
- SVR
- XGBoost
- LightGBM
- CatBoost

## Best Model
SVR achieved the highest performance.

R² Score: 0.091

## Evaluation Metrics
- MAE
- RMSE
- R² Score
