# Gym Exercise Classification using ResNet18

## Project Overview

This project uses Transfer Learning with ResNet18 to classify gym exercises from images.

The objective is to automatically recognize different exercise types using Computer Vision and Deep Learning techniques.

## Technologies Used

- Python
- PyTorch
- ResNet18
- Transfer Learning
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-Learn
- Google Colab

## Results

- Training Accuracy: ~99%
- Test Accuracy: ~97%
- Number of Classes: 8
